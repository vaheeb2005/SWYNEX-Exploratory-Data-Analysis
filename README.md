# SWYNEX Task 2 - Exploratory Data Analysis

## Project Overview

This project was completed as part of the SWYNEX Technologies internship, Task 2: Exploratory Data Analysis (EDA).

The objective is to analyze the prepared Titanic passenger dataset using statistical methods and visualizations to discover patterns, relationships, and insights that may be useful for machine-learning models and decision-making.

## Dataset

- **Dataset:** Titanic Passenger Dataset
- **Source file:** `titanic_cleaned.csv`
- **Target variable:** `Survived` (0 = Did not survive, 1 = Survived)

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Analysis Performed

1. Loaded and inspected the prepared dataset.
2. Examined dataset dimensions, columns, and data types.
3. Calculated descriptive statistics.
4. Analyzed passenger survival distribution.
5. Compared survival rates by gender.
6. Compared survival rates by passenger class.
7. Explored age and fare distributions.
8. Analyzed embarkation ports and survival rates.
9. Created a correlation heatmap for numerical variables.
10. Summarized findings relevant to future machine-learning work.

## Key Insights

1. **Gender and survival:** Survival rates differed by gender, with female passengers generally having a higher survival rate than male passengers.
2. **Passenger class:** Survival outcomes varied across passenger classes. Higher-class passengers generally had better survival rates.
3. **Age distribution:** The dataset includes passengers from different age groups. Age may provide useful predictive information.
4. **Fare distribution:** Passenger fares varied considerably and may reflect differences in passenger class and travel circumstances.
5. **Fare and survival:** Survival rates differed across fare values, suggesting that fare may contain useful predictive information.
6. **Correlation analysis:** The correlation heatmap helps identify relationships among numerical variables and informs potential feature selection.

*Note: These insights should be verified against the actual statistics and visualizations generated by the notebook.*
